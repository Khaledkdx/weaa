# متغيرات نموذج الخدمات اللوجستية

المسار: `/join-us/request-services` (`/request-services` يحوّل إليه)
المكوّن: `frontend/src/serviceInquiryForm.tsx`  
قائمة الخدمات: `frontend/src/serviceInquiry.ts`

## المرحلة الأولى: البيانات

| الحقل الظاهر | اسم المتغير في النموذج | النوع | إلزامي | ملاحظات |
| --- | --- | --- | --- | --- |
| الاسم | `details.name` | نص | نعم | يُرسل في `name` |
| اسم الشركة | `details.company` | نص | لا | يُدمج في `details` |
| رقم الجوال | `details.phone` | نص | نعم | يقبل `05xxxxxxxx` أو `+9665xxxxxxxx`، ويُرسل بصيغة `+9665xxxxxxxx` في `phone` |
| في أي مدينة | `details.city` | نص | نعم | يُدمج في `details` |

## المرحلة الثانية: الخدمات

المتغير `selected` هو مصفوفة نصوص `string[]`. يجب اختيار خدمة واحدة على الأقل. أسماء الخدمات نفسها هي القيم المحفوظة حاليًا؛ لا توجد رموز API مستقلة لها.

### عقود تشغيلية

- `إدارة وتشغيل مشروع لوجستي`
- `عقد استشارات وتطوير`
- `عقد إنشاء وتأسيس مشروع لوجستي`
- `باقة كوادر`
- `عقد جلب أعمال وتشغيل مستودعات`
- `عقد إشراف وتطوير أعمال`

### الاستثمار

- `عقد الهرم الماسي` — استثمار المبالغ المالية في القطاع اللوجستي
- `عقد اتحاد الطبقة الأولى` — التشغيل الثلاثي في توفير المستودعات والمنتجات وتشغيلها ونقلها

الوصف المعروض تحت خيارات الاستثمار لا يُرسل كحقل منفصل. `inquiryDetails(details.company, details.city, selected)` يجمع اسم الشركة والمدينة والخدمات المختارة في نص `details` مقسّم حسب الفئة.

## المرحلة الثالثة: المراجعة والإرسال

المرحلة الثالثة تعرض البيانات فقط، ولا تضيف متغيرات جديدة. عند الضغط على «إرسال الطلب»، يُرسل طلب JSON عبر `POST` إلى `https://app.swarsafqa.com/api/public/customer-service-requests`:

| مفتاح JSON | القيمة المرسلة |
| --- | --- |
| `service_slug` | `logistics-inquiry` |
| `service_title` | `طلب خدمات لوجستية` |
| `name` | `details.name.trim()` |
| `phone` | `+966` ثم الرقم السعودي الموحّد |
| `email` | نص فارغ `""`؛ النموذج لا يطلب بريد العميل |
| `details` | اسم الشركة والمدينة والخدمات المختارة كنص |
| `status` | `طلب جديد` |
| `created_at_label` | التاريخ المحلي العربي وقت الإرسال |

مثال جسم الطلب:

```json
{
  "service_slug": "logistics-inquiry",
  "service_title": "طلب خدمات لوجستية",
  "name": "أحمد",
  "phone": "+966512345678",
  "email": "",
  "details": "اسم الشركة: شركة مثال\n\nالمدينة: جدة\n\nعقود تشغيلية:\n- باقة كوادر\n\nالاستثمار:\n- عقد الهرم الماسي",
  "status": "طلب جديد",
  "created_at_label": "١٤‏/١٠‏/٢٠٢٦"
}
```

هذا النموذج لم يعد يكتب إلى جدول Supabase `service_requests`. لذلك طلباته الجديدة لا تظهر في تبويب «طلبات العملاء» أو ملف CSV المحليين، ولا تشغّل إشعار البريد المرتبط بذلك الجدول. يلزم جلبها من النظام الخارجي أو توفير API للقراءة إذا أردت عرضها داخل أدمن وعاء. تاريخ الإنشاء وإشعاراته مسؤولية النظام الخارجي.

## متغيرات حالة الواجهة

| المتغير | وظيفته |
| --- | --- |
| `step` | المرحلة الحالية: `0` بيانات، `1` خدمات، `2` مراجعة |
| `details` | حقول العميل الأربعة |
| `selected` | أسماء الخدمات المختارة |
| `pending` | منع إرسال الطلب مرتين أثناء الحفظ |
| `error` | رسالة التحقق أو خطأ الإرسال |
| `success` | إظهار تأكيد نجاح الإرسال |

ترويسة الطلب هي `Content-Type: application/json`، ولا تُرسل كلمة سر أو مفاتيح API أو cookies من المتصفح. يجب تأكيد أسماء مفاتيح JSON مع فريق الـ API قبل اعتماد الربط النهائي؛ لم نُرسل طلبًا حقيقيًا أثناء التطوير.

تجربة الإرسال من `localhost` أو `127.0.0.1` قد تفشل بسبب CORS في خادم الطلبات. فحص `OPTIONS` أكد السماح بـ `https://weaa-sa.com` و`https://www.weaa-sa.com` فقط من الأصول المختبرة.
