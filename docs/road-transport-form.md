# نموذج النقل البري

- المسار: `/join-us/road-transport`.
- الوصول: بطاقة «النقل البري» في انضم إلينا، وزر «نموذج النقل البري» في خدمات وعقود.
- المصدر: `رابط_عملاء_النقل_الثقيل.pdf`، سبع صفحات.
- الاستقبال: `join_requests`، بالنوع `form_slug = road-transport`، ويظهر في أدمن وعاء > طلبات النقل البري.

## المراحل والحقول

1. بيانات العميل: الاسم والشركة والهاتف والبريد الإلكتروني.
2. نوع الخدمة: مزود خدمة نقل أو طالب خدمة نقل.
3. المركبات وتفاصيل التشغيل والتعاقد.
4. مراجعة جميع البيانات مع الرجوع للتعديل وتأكيد الإرسال.
5. رسالة نجاح بعد الحفظ فقط.

يدعم النموذج اختيار عدة أنواع مركبات. لكل نوع مختار حقوله المستقلة، ولا تُرسل قيم الأنواع الملغاة. عند تغيير نوع الخدمة تُحفظ بيانات التواصل وتُصفّر التفاصيل السابقة.

| المركبة | بيانات إضافية مشتركة |
| --- | --- |
| فان وهايس | جاف / مبرد / مجمد، العدد، الموديل |
| دينات | جاف / مبرد / مجمد، العدد، الموديل، المقاس، الحمولة بالطن |
| برادات | مبرد / مجمد، العدد، الموديل، المقاس، الحمولة بالطن، نطاق التبريد |
| تريلات | سطحة / ستارة / صندوق مغلق / حاويات / لوبيد / أخرى مع وصف، العدد، الموديل، المقاس، الحمولة بالطن |
| قلابات | العدد، الموديل، الحمولة بالطن |
| تانكر (صهريج) | العدد، الموديل، السعة باللتر |
| رأس تريلا | للمزود فقط: العدد، الموديل |
| أخرى | وصف المركبات ومواصفاتها |

العدد من 1 إلى 999، والموديل من 2000 إلى 2027 كما في الملف. السعة والحمولة أرقام موجبة، مع قبول الأرقام العربية. يضيف مسار المزود حالة المركبة: جديدة / ممتازة / جيدة / متوسطة.

المشترك: السائق، الوقود، المدينة، نطاق العمل (داخل المدينة / بين المدن / عمل دولي)، والملاحظات. للمزود تصريح دخول الميناء، واختيار متعدد لطرق التعاقد (إيجار شهري / عقد سنوي / بالطلب). للطالب نوع الحمولة، واختيار واحد لطريقة التعاقد، ومدة العقد المتوقعة.

تُحفظ جميع التفاصيل بعناوين عربية في `fields`، ويُضاف تاريخ الطلب تلقائيًا من قاعدة البيانات. لم يتضمن الملف مرفقات أو API خارجيًا؛ الإرسال يستخدم اتصال Supabase الحالي دون إضافة جدول جديد.
